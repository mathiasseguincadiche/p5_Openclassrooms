# Schémas pédagogiques

Les schémas sont volontairement compacts pour rester lisibles dans un README,
un fichier Markdown, un navigateur et un export PDF.

Principes :

- aucun Mermaid ni moteur de rendu externe ;
- format SVG statique léger ;
- pas d’ombre, de filtre ou d’illustration décorative ;
- une idée principale par schéma ;
- texte court et contraste suffisant.
