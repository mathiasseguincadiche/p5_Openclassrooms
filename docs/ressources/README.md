# Ressources pédagogiques du P5

Ces contenus préparent les exercices. **Ils ne constituent pas quatre exercices
supplémentaires.**

## Avant l'exercice 1 — Terraform

Concentrez-vous sur :

- infrastructure as code ;
- providers, ressources et variables ;
- `init`, `plan`, `apply`, état et versionnage ;
- bonnes pratiques de nommage, modules et variables sensibles.

## Avant l'exercice 1 — Ansible

Concentrez-vous sur :

- installation d'Ansible ;
- inventaires ;
- tâches et playbooks ;
- handlers ;
- exécution reproductible sur plusieurs serveurs.

La création de modules Python personnalisés est un approfondissement du cours,
pas une exigence du livrable P5.

## Avant l'exercice 2 — Monitoring

Concentrez-vous sur :

- sources de logs ;
- collecte et structuration ;
- centralisation avec ELK ;
- recherche dans Discover ;
- visualisations et détection d'incidents.

## Avant l'exercice 3 — AWS

Concentrez-vous sur :

- principes du Cloud et responsabilité des coûts ;
- création et accès à une instance EC2 ;
- groupes de sécurité ;
- hébergement d'un service web ;
- disponibilité et scalabilité.

RDS et S3 sont abordés dans le cours AWS, mais ne sont pas nécessaires pour les
trois exercices décrits dans les consignes fournies.
