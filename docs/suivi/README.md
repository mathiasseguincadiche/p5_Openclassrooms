# Suivi interne du projet

Ce dossier contient deux documents facultatifs, distincts des livrables :

- [Décisions techniques](decisions-techniques.md)
- [Modèle de journal de session](journal-de-session.md)

Ils servent à préparer les échanges avec le mentor et à expliquer les choix. Le journal est un modèle à copier localement avant utilisation ; il ne représente pas un état d’avancement du dépôt.

Ces documents ne remplacent pas les preuves réelles demandées pour les trois exercices.
