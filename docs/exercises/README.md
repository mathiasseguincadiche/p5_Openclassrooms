# 🎯 Exercices pédagogiques

Ces exercices présentent progressivement les outils DevOps utilisés autour du
projet P5. Ils peuvent être suivis indépendamment du parcours AWS principal.

| Exercice | Sujet | Outils | Niveau |
| --- | --- | --- | --- |
| [1](./exercise-1/README.md) | Conteneuriser une application | Docker, Docker Compose | Débutant |
| [2](./exercise-2/README.md) | Construire une CI/CD | GitHub Actions, Docker | Débutant/intermédiaire |
| [3](./exercise-3/README.md) | Configurer des serveurs | Ansible, SSH | Intermédiaire |
| [4](./exercise-4/README.md) | Décrire une infrastructure | Terraform, cloud | Intermédiaire |
| [5](./exercise-5/README.md) | Orchestrer des conteneurs | Kubernetes, Docker | Avancé |

Pour le parcours de réalisation P5 et ses trois infrastructures AWS, revenez au
[README principal](../../README.md).
